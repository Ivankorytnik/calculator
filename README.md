# Калькулятор финмодели MVP v2

Обновленная версия интерактивной финансовой модели проекта «Желание сквозь Вселенную».

Источник расчетной логики: обновленный Excel-файл `Желание_сквозь_Вселенную_финмодель_12м(1).xlsx`.

## Основной принцип интерфейса

- минимум декоративных элементов;
- компактная верхняя панель;
- исходные данные всегда слева;
- ключевые показатели и графики справа;
- изменение любой вводной сразу пересчитывает модель;
- отдельный план заказов на каждый месяц;
- дополнительные параметры команды, OPEX и CAPEX доступны в раскрывающихся блоках.

## Что рассчитывается

- платежи клиентов и выручка без НДС;
- НДС после превышения порога;
- переменные расходы;
- ФОТ и страховые взносы;
- OPEX;
- стартовый и дополнительный CAPEX;
- операционная прибыль;
- УСН;
- чистый и накопленный денежный поток;
- требуемое финансирование;
- месяц окупаемости;
- ROI;
- доход РТ-64;
- пиковый штат и консьерж-служба;
- точка безубыточности.
